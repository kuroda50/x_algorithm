# X レコメンド・ビートファクトリー

X（旧 Twitter）のおすすめフィードのアルゴリズムを、工場のラインに見立てて可視化するブラウザ用シミュレーション。投稿がビートに合わせて機械から機械へ流れ、エージェント（仮想ユーザー）の反応が、人ごとのフィードの偏り（フィルターバブル）を作っていく様子を眺められます。

## 起動

```bash
npm install
npm run dev
```

テスト・型チェック・ビルド:

```bash
npm test
npm run typecheck
npm run build
```

## 画面の見方

- **ライン（上の Canvas）**: 投稿（話題ごとの色と図形）が、フォロー内 / フォロー外の 2 つの搬入口からベルトに載って合流し、検品機（フィルタ）・プレス（スコアリング）・削り機（多様性調整）・仕分けゲート（選抜）を通って、右側の「興味の街」にいるエージェントへ届きます。機械を通るたびに絞り込まれ、届くのは一部です。不良品はスクラップ箱へ、選抜で漏れたものは落選箱へ落ちます。エージェントは興味が偏るほど、その話題の地区へ寄っていきます。周りの輪はフィードの話題構成です。
- **フィード（左下）**: エージェントをクリックすると、その人の興味ベクトルとフィード上位 6 件が表示されます。未選択時は全エージェントのフィード構成の一覧が出ます。
- **フィードの偏り（右下）**: 偏り指数とエージェント間の類似度の時系列。偏り指数が上がり、類似度が下がるほど、人ごとにフィードが分かれています。
- **スライダー**: スコアリングの重み・多様性ペナルティ・フォロー外の係数・興味の更新速度などを変えられます。

## 音と機械の対応

鳴っている音には、必ず同じ瞬間に動く機械があります。全機械が 1 拍で 1 周します。

| 音 | 拍の中の位置 | 画面で起きること |
|---|---|---|
| キック | 拍の頭 | プレス（スコアリング）と削り機（多様性調整）が打つ。4 拍ごとに強い |
| ハット | 裏拍 | 搬入口のシャッターが開き、新しい投稿が出る |
| 低い音 | 0.75 拍 | 検品機がスパムや古い投稿をはじき、スクラップ箱に落ちる |
| カチッ | 0.75 拍 | 仕分けゲートのアームが、選抜で漏れた投稿を払い落とす |
| 話題の音 | 0.75 拍〜 | 投稿がエージェントに届く。話題ごとに音の高さが違う |
| 高い音 | その直後 | エージェントが反応した |

## 工程と X のアルゴリズムの対応

公開されている構成（xai-org/x-algorithm と、2023 年公開の twitter/the-algorithm）に対応しています。

| 工程 | 実際の構成 | このシミュレーションでの処理 |
|---|---|---|
| 0: フォロー内（搬入口） | Thunder: フォロー中アカウントの最近の投稿 | フォローしている投稿者の未読の新しい投稿の中から、興味に近いもの |
| 0: フォロー外（搬入口） | Phoenix Retrieval: 埋め込み類似度で取得 | フォローしていない投稿者の未読投稿を、興味との近さ順に |
| 1: フィルタ（検品機） | Pre-scoring filters | スパムと古すぎる投稿を除外 |
| 2: スコアリング（プレス） | Phoenix Scorer + Weighted Scorer | `score = wLike·P(いいね) + wReply·P(リプライ) + wRepost·P(リポスト)` |
| 3: 多様性調整（削り機） | Author Diversity Scorer / OON Scorer | 同じ投稿者の 2 件目以降を減衰、フォロー外に係数を掛ける |
| 4: 選抜（仕分けゲート） | Selection | スコア上位 K 件だけがフィードへ進む |
| 5: エージェント | フィード表示。行動が次回の入力になる | 反応すると興味ベクトルが更新される |

## 簡略化している点

- 予測モデル（いいね・リプライ・リポストの確率）の代わりに、話題ごとの興味ベクトルと投稿の品質から決めています。数値は実際の値ではありません。
- 反応はいいね・リプライ・リポストの 3 種類だけです。
- 反応すると、その話題の興味が今の興味に比例して増えます（反応がなければ少し減ります）。フォロー外の投稿にリプライ・リポストすると、一定の確率でその投稿者をフォローします。
- 候補は 1 回の要求につきフォロー内 4 件・フォロー外 4 件だけです。実際は桁違いに多く取ってから絞り込みます。
- 最初は全員が、どの話題からも同じ人数をフォローし、興味もほぼ均等です。差は反応の積み重ねだけから生まれます。
- 投稿者・話題・エージェントはすべてシード付き乱数で生成する仮想のもので、実データは使いません。
