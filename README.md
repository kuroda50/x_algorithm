# X レコメンド・ビートメトロ

X（旧 Twitter）のおすすめフィードのアルゴリズムを、地下鉄の路線図に見立てて可視化するブラウザ用シミュレーション。投稿がビートに合わせて駅から駅へ移動し、エージェント（仮想ユーザー）の反応が、人ごとのフィードの偏り（フィルターバブル）を作っていく様子を眺められます。

## 起動

```bash
npm install
npm run dev
```

テスト・型チェック・ビルド:

```bash
npm test
npm run typecheck
npm run build
```

## 画面の見方

- **路線図（上の Canvas）**: 投稿（話題ごとの色と図形）が、フォロー内/フォロー外の 2 本の始発駅から合流し、フィルタ・スコアリング・多様性調整・選抜の駅を通って、右側の「興味の街」にいるエージェントへ届きます。駅を通るたびに絞り込まれ、届くのは一部です。エージェントは興味が偏るほど、その話題の地区へ寄っていきます。周りの輪はフィードの話題構成です。
- **フィード（左下）**: エージェントをクリックすると、その人の興味ベクトルとフィード上位 6 件が表示されます。未選択時は全エージェントのフィード構成の一覧が出ます。
- **フィードの偏り（右下）**: 偏り指数とエージェント間の類似度の時系列。偏り指数が上がり、類似度が下がるほど、人ごとにフィードが分かれています。
- **スライダー**: スコアリングの重み・多様性ペナルティ・フォロー外の係数・興味の更新速度などを変えられます。

## 駅と X のアルゴリズムの対応

公開されている構成（xai-org/x-algorithm と、2023 年公開の twitter/the-algorithm）に対応しています。

| 駅 | 実際の構成 | このシミュレーションでの処理 |
|---|---|---|
| 0: フォロー内 | Thunder: フォロー中アカウントの最近の投稿 | フォローしている投稿者の未読の新しい投稿の中から、興味に近いもの |
| 0: フォロー外 | Phoenix Retrieval: 埋め込み類似度で取得 | フォローしていない投稿者の未読投稿を、興味との近さ順に |
| 1: フィルタ | Pre-scoring filters | スパムと古すぎる投稿を除外 |
| 2: スコアリング | Phoenix Scorer + Weighted Scorer | `score = wLike·P(いいね) + wReply·P(リプライ) + wRepost·P(リポスト)` |
| 3: 多様性調整 | Author Diversity Scorer / OON Scorer | 同じ投稿者の 2 件目以降を減衰、フォロー外に係数を掛ける |
| 4: 選抜 | Selection | スコア上位 K 件だけがフィードへ進む |
| 5: エージェント | フィード表示。行動が次回の入力になる | 反応すると興味ベクトルが更新される |

## 簡略化している点

- 予測モデル（いいね・リプライ・リポストの確率）の代わりに、話題ごとの興味ベクトルと投稿の品質から決めています。数値は実際の値ではありません。
- 反応はいいね・リプライ・リポストの 3 種類だけです。
- 反応すると、その話題の興味が今の興味に比例して増えます（反応がなければ少し減ります）。フォロー外の投稿にリプライ・リポストすると、一定の確率でその投稿者をフォローします。
- 候補は 1 回の要求につきフォロー内 4 件・フォロー外 4 件だけです。実際は桁違いに多く取ってから絞り込みます。
- 最初は全員が、どの話題からも同じ人数をフォローし、興味もほぼ均等です。差は反応の積み重ねだけから生まれます。
- 投稿者・話題・エージェントはすべてシード付き乱数で生成する仮想のもので、実データは使いません。
